# Figma wireframe reference

`figma-wireframes.svg` is a **five-screen static SVG sheet** for importing into a new Figma file using drag-and-drop. It is a starting **visual reference**, not a native Figma component library or a live backend-connected design. The matching runnable screens are in `apps/mobile/src/screens/`. Rebuild reusable Figma Auto Layout components using `docs/FIGMA_HANDOFF.md` and keep the typography, touch targets and disclaimers accessible.
